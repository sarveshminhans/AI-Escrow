# AI-Escrow

AI-powered escrow web application with a Vite/React frontend, Flask AI API, and Solidity smart contract.

## Vercel deployment
- Frontend: Vite/React
- API: Vercel Python function at /api/chat
- Required environment variable: HF_TOKEN
- Smart contract source: smartcontract/src/Escrow.sol

See VERCEL_DEPLOY.md for deployment notes.
